LSC Smart Connect ist Tuya-kompatibel

Die Kameras von Action (LSC) basieren vollständig auf der Tuya-Plattform. Sie können diese Geräte direkt im Tuya IoT-Portal registrieren und steuern. Dieses Hub hilft Ihnen, die Endpunkte aus Ihren hochgeladenen Dokumenten zu implementieren.

Wie funktioniert die Live-Stream-Architektur?

Die Tuya IoT-Plattform ermöglicht es Ihren Kameras, Ströme auf verschiedene Arten zu verteilen. Während RTSP und HLS über Relayservers laufen (die Bandbreite verbrauchen und verzögert sind), ermöglicht WebRTC eine extrem latenzfreie Peer-to-Peer-Direktverbindung zwischen Kamera und Browser/App.

Möglichkeit B: RTSP / HLS (Einfach, 2s-10s)
API-Aufruf zu `/v1.0/devices/{id}/stream/actions/allocate` ➔ Tuya Cloud liefert Stream-URL ➔ Player lädt HLS-Manifest oder NVR greift per RTSP zu.

Die 3 API-Endpunkte aus Ihren Dokumenten:

GET /v1.0/devices/{device_id}/webrtc-configs

Holt die STUN/TURN Server, Credentials und P2P-Fähigkeiten für WebRTC.

POST /v1.0/devices/{device_id}/stream/actions/allocate

Generiert direkte Stream-Adressen für RTSP oder HLS (wird nach Gerät zugewiesen).

POST /v1.0/users/{uid}/devices/{device_id}/stream/actions/allocate

Gleiche Allokation, jedoch gebunden an die spezifische Benutzer-ID (UID).

Voraussetzungen

  • Kamera gekoppelt: Die LSC Kamera muss in der LSC-App oder direkt in der Tuya-App / Smart Life App angemeldet sein.
  • Tuya Cloud Account: Registrieren Sie sich auf iot.tuya.com.
  • Link Devices: Verknüpfen Sie Ihren LSC/SmartLife-Account mit dem Cloud-Projekt unter "Cloud ➔ Link Tuya App Account".
  • API-Service aktiviert: Das Service-Paket "IoT Video Live Stream" muss in Ihrem Tuya-Projekt aktiv sein.

Wichtig bei LSC Kameras

Einige LSC-Kameramodelle unterstützen standardmäßig kein lokales RTSP im Heimnetzwerk (Port 554 ist geschlossen). Durch die Integration der Tuya WebRTC / Cloud API umgehen Sie dieses Problem, da der Stream verschlüsselt über den Tuya-Tunnel nach außen gereicht und überall abrufbar gemacht wird!

Live HLS Stream Tester

HLS (HTTP Live Streaming) ist das ideale Protokoll für Web-Anwendungen, da es nativ im Browser wiedergegeben werden kann. Wenn Sie über den API-Endpunkt eine HLS-URL generiert haben (beginnend mit https://...), können Sie diese hier einsetzen und direkt abspielen.
