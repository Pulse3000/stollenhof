# Kuh-Bilder für 3D-Stallvorschau

Lege hier PNG-Bilder der Kühe ab. Die Datei muss der Stallplatz-Nummer entsprechen.

- `1.png` → Kuh Nr. 01 (Alma)
- `2.png` → Kuh Nr. 02 (Berta)
- `3.png` → Kuh Nr. 03 (Clara)
- ...
- `30.png` → Kuh Nr. 30

Empfehlung: transparenter Hintergrund (alpha), Hochformat ca. 600 × 800 px.

Fehlt ein Bild, zeigt die 3D-Vorschau eine farbige Platzhalter-Fläche an
(Farbe richtet sich nach dem Status: braun = gesund, rot = in Behandlung,
pink = trächtig, grau = trockengestellt).
